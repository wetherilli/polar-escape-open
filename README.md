# 한밤의 극지연구소

극지연구소에서 끝나지 않는 밤에 갇힌 고등학생 수오의 이야기 — 쯔꾸르풍 탐색 게임입니다. **아직 만드는 중**입니다.

▶ 플레이: https://wetherilli.github.io/polar-escape-open/

인터넷 없이 하려면 [`polar-escape-offline.html`](polar-escape-offline.html)을 내려받아(파일 화면의 「Download raw file」) 더블클릭하면 됩니다.
파일 하나에 게임이 다 들어 있습니다. 이 파일로 한 진행은 웹판과 따로 저장됩니다.

## 조작

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| Shift (누른 채 이동) | 달리기 |
| Enter / F | 조사 · 대사 넘기기 · 선택 |
| E | 소지품 |
| L | 손전등 켜기·끄기 |
| Esc / Q | 메뉴 · 취소 |

진행은 브라우저에 저장됩니다(기기·브라우저를 바꾸면 이어지지 않습니다).

이 저장소는 공개 배포본입니다. 게임 속 장소는 실제 기관을 배경으로 하지만, 배치와 내용은 창작이 섞여 있습니다.
